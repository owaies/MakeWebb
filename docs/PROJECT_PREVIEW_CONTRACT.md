# MakeWebb project preview contract

Each portfolio project preview should communicate a distinct product identity without changing the surrounding navigation model.

## Required content
- Project name
- Project type
- Technology or capability summary
- A clear visual preview
- A reachable project destination when one exists

## Interaction
Hover, scroll, and pointer effects should enhance the preview without hiding its title or action controls.

## Responsive behavior
On touch devices, hover-only information must have an accessible alternative.
