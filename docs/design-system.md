# MakeWebb visual system

MakeWebb is a digital product studio, so the interface should communicate technology through motion without sacrificing readability.

## Design principles

- Give each project a distinct visual identity while keeping typography and spacing coherent.
- Use motion to reinforce hierarchy and navigation, not to hide content.
- Keep project information readable across desktop, tablet, and mobile layouts.
- Prefer reusable interaction patterns for cards, transitions, and navigation.
- Test high-motion sections with reduced-motion preferences enabled.
