# MakeWebb Route Model

The Vite/React application uses route components for the main studio pages.

## Current pages

The repository contains routes for home, services, work, team, and contact, with shared navigation and footer components.

## Change discipline

Keep route-specific content in its page or component boundary. Shared motion primitives such as reveal, smooth scroll, tilt cards, and cursor effects belong in reusable components rather than being duplicated across every page.

For new routes, update navigation, direct-link behavior, and the project's route and error handling together.
