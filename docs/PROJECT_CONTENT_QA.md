# Project content QA

Every featured project should be checked as a complete product card and destination.

## Content
Verify title, category, technology summary, preview, and destination are current.

## Links
Open project links from the production site and confirm they resolve to the intended destination.

## Visuals
Check image aspect ratios, loading states, contrast, and mobile cropping.

## Consistency
Keep naming and project identifiers consistent across project cards, filters, and detail views.
